A tiny Python program that writes one original out-of-office auto-reply from a long-ignored office fern — last watered in March, still alive out of spite — to entry.txt (115 characters, within the 120-character cap) for make.fun's "The Houseplant Out-of-Office" bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
